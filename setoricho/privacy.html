「セトリ帳」プライバシーポリシー

最終改定日: 2026年8月1日

OPATECH(以下「当方」といいます)は、当方が提供するアプリ「セトリ帳」(以下「本アプリ」といいます)における、ユーザーの情報の取り扱いについて、本ポリシーを定めます。

1. 収集する情報と取得方法

  • Googleアカウント情報: 本アプリはGoogleアカウントでのログインが必須です。ログインの際、Googleからメールアドレス・表示名・プロフィール画像などの基本情報を取得します。
  • Googleカレンダーの情報: ログインしたGoogleアカウントのカレンダーに対して、ライブ予定・セットリスト等の読み書きを行います。本アプリが作成・編集するのはユーザー自身が操作したカレンダー予定のみで、それ以外の既存の予定内容を外部に送信することはありません。
  • 写真・動画: 端末の写真ライブラリへのアクセス許可をいただいた上で、ユーザーが選択した写真・動画を各ライブの記録に紐づけます。通常はファイル本体をコピーせず、端末内の資産IDのみを保存します。
  • フライヤー画像・テキストの解析: 「インポートして登録」機能を使った場合のみ、ユーザーが選択した画像またはテキストを、ライブ情報を自動抽出するために当方のサーバー(Cloud Functions)を経由して解析します。解析後、当方のサーバーに画像・テキストを保存することはありません。
  • 購入情報: アプリ内課金(クレジット購入)は、Apple/Googleの決済基盤を通じて処理されます。当方が保持するのは購入結果に基づくクレジット残高のみで、クレジットカード情報等の決済手段そのものを当方が取得・保存することはありません。
  • 広告識別子: 本アプリはGoogle AdMobによる広告を表示します。広告配信に伴い、端末の広告識別子等がGoogleによって取得される場合があります。詳細はGoogleのプライバシーポリシーをご確認ください。

2. 情報の利用目的

  • 本アプリの主要機能(カレンダー同期、セットリスト記録、フライヤー自動読み取り、ライブ前日通知、検索)を提供するため
  • アプリ内課金の処理、購入済みクレジット残高の管理・復元(再インストール時)のため
  • 広告の表示のため
  • 不具合の調査・お問い合わせへの対応のため

3. 第三者への提供

当方は、法令に基づく場合を除き、取得した情報を本人の同意なく第三者に提供することはありません。ただし、本アプリの機能提供に必要な範囲で、以下の外部サービスに情報を送信します。

  • Google(Googleカレンダー API / Googleサインイン / AdMob / Firebase): ログイン認証、カレンダー同期、広告配信、購入クレジット残高の保存のため
  • Anthropic: フライヤー画像・告知テキストからライブ情報を抽出するため、当方サーバー経由で一時的に送信されます。送信された内容は本アプリの機能提供以外の目的には利用されません

4. データの保護

  • 本アプリと当方サーバー間の通信、および当方サーバーと外部サービス(Google, Anthropic等)との通信は、すべてTLSにより暗号化されています。
  • 当方サーバー(Firebase Cloud Functions)へのアクセスは、認証済みのユーザーからのリクエストに限定されており、第三者が不正に情報へアクセスできないようアクセス制御を行っています。
  • 取得した情報は、本ポリシーに記載した利用目的の達成に必要な範囲でのみ利用し、必要以上に保持しません。

5. AI技術の利用について(Limited Use)

本アプリの「インポートして登録」機能では、ユーザーが選択したフライヤー画像・告知テキストの解析にAnthropic社のAIモデル(Claude)を利用しています。この解析によって得られたデータの取り扱いは、Google API Services User Data PolicyのLimited Use要件を含む、Googleユーザーデータポリシーを遵守します。具体的には、Googleカレンダー等のGoogleサービスから取得したデータを、汎用的または基盤的なAI/機械学習モデルの構築・学習・改善のために使用、譲渡、または販売することはありません。AIによる解析結果は、ユーザー自身が内容を確認・編集した上でカレンダーに登録するための下書き作成のみに利用されます。

6. 情報の保存期間

  • 端末内にのみ保存される情報(下書き、無料枠の利用回数など)は、アプリを削除すると消去されます。
  • Googleカレンダー上のライブ予定は、ユーザー自身がGoogleカレンダー上で削除しない限り保持されます(当方はこれを独自に削除しません)。
  • 購入クレジット残高は、再インストール時の復元のためGoogleアカウントに紐づけてサーバー側に保存されます。削除をご希望の場合は下記お問い合わせ先までご連絡ください。
